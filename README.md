# Muhammad Lutfi Wibowo — Portfolio

A responsive one-page engineering portfolio for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — layout and styling
- `script.js` — mobile navigation and scroll animations
- `assets/` — put your CV, project images, certificates, and other files here

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the LinkedIn and GitHub links with your actual profiles.
3. Replace the WhatsApp placeholder with your number in international format.
4. Put your CV at `assets/Muhammad-Lutfi-Wibowo-CV.pdf`.
5. Add project/documentation images if desired.

## GitHub Pages
Create a GitHub repository, upload all files, then go to:
Settings → Pages → Deploy from branch → `main` → `/root`.

The site will then be available at your GitHub Pages URL.
